# 节制天下兵马：住所庄园管理大师
**给你的住所加上“符文页”，保存多套建筑搭配，按需切换。**

CK3 的住所建筑槽位有限，一套庄园很难兼顾所有需求。偏重军事，就要舍弃一些经济建筑；想换一种搭配，又要拆掉原来的建筑重新建设。

这个 Mod 让同一个人物拥有多处辅助住所，分别建设不同的建筑组合。准备打仗，就把偏军事的建筑组合换进默认住所；安心发展，再换上另一套。换下来的附属建筑会存入辅助住所，下次还能换回来。

## 创建多处住所，保存不同的建筑搭配
通过「创建住所头衔」决议，可以反复创建伯爵、公爵、国王、帝国或霸权等级的辅助住所头衔，不设数量上限，也不额外收取创建费用或设置冷却。

住所类型根据创建者当前政体生成。头衔等级与住所主建筑等级分开：高等级头衔不等于高等级建筑。创建高于现有主头衔的住所头衔，可能按游戏规则改变主头衔等状态。

## 在自己的住所之间切换建筑
在默认住所与同类型辅助住所之间，交换外部和内部附属建筑；双方主建筑采用较高等级，不会因交换而降级。

支持六类住所的同类型交换：**家族庄园、东亚庄园、日式庄园、营地、毡帐和教会住所**。不同类型的住所不能互换建筑；其他 Mod 新增的建筑不会自动纳入交换。

## 分别打开和建设每一处住所
通过「管理所有住所」决议或头衔页面，打开对应头衔实际绑定的住所。每一处住所都可以单独查看、建设和管理。

保留本人辅助住所的建设入口，也提供作为最高领主时对封臣住所的建设入口。正常建设仍使用游戏原本的费用与建筑条件。

## 授予、抄没和管理住所头衔
右键人物，通过「授予住所头衔」「抄没住所头衔」转交符合条件的住所头衔及其住所。这两项使用游戏原有的授予、剥夺处理，保留相应的费用、好感、暴政以及接受或拒绝机制。

「无地头衔管理」互动还提供头衔标记、创建普通无地头衔、授予与剥夺、调整法理、迁移法理首都、搬迁住所等操作。普通无地头衔的创建与绑定住所的创建是两条不同入口。

## 汇集资源，拆除闲置的额外住所
使用「合并辅助住所资源」，把辅助营地的给养、辅助毡帐的牧群汇集到默认住所；容量不足的部分留在原住所。

拆除本 Mod 创建的额外住所前需要确认。可补偿的建筑资源会返还，实际补偿数额显示在消息栏。给养和牧群优先转移到本人其他同类型住所，不能转移的部分随该额外住所消失。

## 推荐搭配：节制天下兵马：无地头衔管理器
如果还希望通过图鉴选择多种专有头衔、自由选择原生住所类型，并集中编辑头衔属性，可以搭配「节制天下兵马：无地头衔管理器」使用。本作侧重多住所的建筑搭配、建设和资源管理，两者仍是独立 Mod。

住所庄园管理大师 1.2.1 与无地头衔管理器 0.4.4 使用统一的头衔详情页，保留双方的页面入口。人物互动中的两套头衔标记分别保存。

[无地头衔管理器 · GitHub](https://github.com/apo-so/ck3-landless-title-manager)

## 使用说明与兼容
- 适配 CK3 1.20.1，提供简体中文和英文。
- 目前只开放本人住所之间的建筑交换，与封臣交换建筑暂时关闭。
- 游牧身份头衔暂不开放转交；原生住所载体和来源不明的住所不能拆除。
- 本作覆盖头衔界面、住所界面、住所相关 on_action 和六类住所建筑定义。修改相同文件的 Mod 需要合并兼容；上述统一头衔页仅解决两款指定版本之间的头衔页面覆盖。
