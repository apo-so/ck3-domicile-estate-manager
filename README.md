# 节制天下兵马：住所庄园管理大师

**给你的住所加上“符文页”，保存多套建筑搭配，按需切换。**

CK3 的住所建筑槽位有限，一套庄园很难兼顾所有需求。偏重军事，就要舍弃一些经济建筑；想换一种搭配，又要拆掉原来的建筑重新建设。

这个 Mod 让同一个人物拥有多处辅助住所，分别建设不同的建筑组合。准备打仗，就把偏军事的建筑组合换进默认住所；安心发展，再换上另一套。换下来的附属建筑会存入辅助住所，下次还能换回来。

**换一套建筑**　先用「创建住所头衔」增设住所，再打开「管理所有住所」。在想与默认住所对调的那一行点「交换建筑」，最后点「确认交换建筑」。

## 更新公告｜2026年11月19日

**住所庄园管理大师 1.2.6 适配 CK3 1.21.0「Florin」。**

- **商会成为第七类住所。**　商人和共和制角色可以通过「创建住所头衔」建立辅助商会，在「管理所有住所」中建设和交换建筑。拆除本模组创建的辅助商会时，会返还可补偿的建筑资源。
- **恢复与封臣交换庄园。**　七类住所都支持。右键直属封臣或其下属，选择「交换庄园」，即可对调双方同类型默认住所的外部和内部附属建筑。
- **与封臣交换时，主建筑可以不同级。**　确认后，较低的一方先升至较高等级，两边都保留该等级。例如，2 级与 4 级交换后，两座主建筑都是 4 级。

## 创建多处住所，保存不同的建筑搭配

通过「创建住所头衔」决议，可以反复创建伯爵、公爵、国王、帝国或霸权等级的辅助住所头衔，不设数量上限，也不额外收取创建费用或设置冷却。

住所类型根据创建者当前政体生成。头衔等级与住所主建筑等级分开：高等级头衔不等于高等级建筑。创建高于现有主头衔的住所头衔，可能按游戏规则改变主头衔等状态。

## 在自己的住所之间切换建筑

在默认住所与同类型辅助住所之间，交换外部和内部附属建筑；双方主建筑采用较高等级，不会因交换而降级。

支持七类住所的同类型交换：**家族庄园、东亚庄园、日式庄园、营地、毡帐、教会住所和商会**。不同类型的住所不能互换建筑；其他 Mod 新增的建筑不会自动纳入交换。

商人政体的「贸易商会」和共和制的「商行」都属于商会。每座辅助商会都有独立的住所头衔。如果新建的商会成了默认住所，就从原商会那一行点「交换建筑」。交换时，交易、仓储、民政和生产建筑会连同各自的分支、等级和内部建筑一起对调。

## 与封臣交换庄园

右键直属封臣或封臣的下属，在「外交」中选择「交换庄园」，发送后点「确认交换」。交换的是双方当前默认住所里的附属建筑。两座住所须为同一类型，政体名称和主建筑等级可以不同。

确认后，先把较低的主建筑升到较高一方的等级，双方保留这个等级，再按原等级对调外部和内部附属建筑。双方各自持有原来的头衔，住所也留在原地。点「取消」时双方建筑保持原样。

## 分别打开和建设每一处住所

通过「管理所有住所」决议或头衔页面，打开对应头衔实际绑定的住所。每一处住所都可以单独查看、建设和管理。

保留本人辅助住所的建设入口，也提供作为最高领主时对封臣住所的建设入口。正常建设沿用原版费用和建筑条件。替封臣建造或升级时，由住所主人支付费用。

## 授予、抄没和管理住所头衔

右键人物，通过「授予住所头衔」「抄没住所头衔」转交符合条件的住所头衔及其住所。这两项使用游戏原有的授予、剥夺处理，保留相应的费用、好感、暴政以及接受或拒绝机制。

「无地头衔管理」互动还提供头衔标记、创建普通无地头衔、授予与剥夺、调整法理、迁移法理首都、搬迁住所等操作。普通无地头衔的创建与绑定住所的创建是两条不同入口。

## 汇集资源，拆除闲置的额外住所

使用「合并辅助住所资源」，把辅助营地的给养、辅助毡帐的牧群汇集到默认住所；容量不足的部分留在原住所。

拆除本 Mod 创建的额外住所前需要确认。可补偿的建筑资源会返还，实际补偿数额显示在消息栏。给养和牧群优先转移到本人其他同类型住所，不能转移的部分随该额外住所消失。

## 推荐搭配：节制天下兵马：无地头衔管理器

## 使用说明与兼容

- 适配 CK3 1.21.0（Florin），提供简体中文和英文。
- 游牧身份头衔暂不开放转交；原生住所载体和来源不明的住所不能拆除。
- 本作改动头衔页面、住所页面、住所相关事件和七类原版住所建筑。与改动同一部分的 Mod 合用时，需要相应的兼容补丁。
- 本作已经包含封臣庄园建设。[《解锁建设封臣庄园》](https://steamcommunity.com/sharedfiles/filedetails/?id=3759790829)也修改住所窗口和「交换庄园」互动，同一播放集请择一启用。
