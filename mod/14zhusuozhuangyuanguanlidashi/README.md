# 节制天下兵马：住所庄园管理大师 1.2.6

适配《十字军之王 III》1.21.0 Florin（Steam Build 26622941）。提供简体中文和英文。商人政体的「贸易商会」和共和制的「商行」共用第七套住所管理逻辑。

## 安装与升级

将压缩包中的 14zhusuozhuangyuanguanlidashi 文件夹及同名 .mod 文件解压到文档目录 Paradox Interactive/Crusader Kings III/mod。已有本地版时覆盖同名文件，在启动器启用「节制天下兵马：住所庄园管理大师」。工坊关联为 3819185353。

## 与无地头衔管理器合用

两个 Mod 可以分别启用。《无地头衔管理器》0.4.7-test1 的 1.21 适配候选与此版共用同一份头衔详情页。合用时保留标记 B 与庄园快捷操作。若仍搭配带有旧版头衔页的 0.4.6-test5，将庄园管理大师排在其后，使 1.21 页面生效。

## 商会与商行

1. 以商人或共和制人物打开「创建住所头衔」，可选伯爵、公爵、国王、帝国或霸权。每座辅助商会拥有独立住所头衔，原生家族头衔继续持有原商会。通过「管理所有住所」或头衔页打开指定商会。
2. 在「住所管理」中，选择「交换建筑」亮起的那一行。新建商会可能成为默认住所，此时从原生商会一行发起交换。两个总部均保留较高等级。交易、仓储、民政及生产四条外部建筑线先重建至对方的具体分支，再恢复各自的内部建筑。操作结束会逐项核对。核对失败会尝试恢复原配置，未恢复的住所会在下次交换时先继续恢复。
3. 对本 Mod 创建的辅助商会选择「销毁」并确认。建筑按原生规则结算，消息显示实际到账金额。若有应结算的建筑仍然存在，系统保留头衔供重试。原生贸易商会与商行受住所头衔禁毁规则保护。

## 住所创建与管理

“创建住所头衔”决议提供伯爵、公爵、国王、帝国、霸权五个等级，可反复创建辅助住所，不加数量、费用或冷却限制。根据当前政体创建相应默认住所类型，支持行政制、无地冒险者、游牧制、天朝制、草原行政制、贤能制、日本行政制、日本封建制、教权制、商人及共和制。

头衔等级与主建筑等级独立；创建高等级头衔可能按本体规则改变主头衔、领属、军队及默认住所。通过“管理所有住所”决议或头衔页面入口打开列表，每个有住所的头衔均可打开其实际住所。列表固定约五至六行，更多条目滚动查看；列表编号刷新后可能变化。

## 无地头衔管理互动

右键自己或目标人物，选择“无地头衔管理”。在本体头衔选择面板中选择此人持有的头衔，再选择标记、创建无地头衔、剥夺、授予、迁移法理首府、搬迁该头衔的实际住所、调整法理或销毁。标记保存在玩家身上，可用于对另一人的后续操作。创建普通无地头衔使用伯爵至霸权的本体事件选择，不附带住所；创建住所方案仍使用“创建住所头衔”决议。

住所授予/抄没使用现有专用互动；本人额外住所销毁使用现有确认与补偿链，原生住所载体继续保护。不恢复独立无地头衔管理器窗口，也不改变封臣/本人辅助住所建设按钮。

本次菜单恢复已完成源码核对与部署；按用户要求不进行实机测试，不能引用前轮验收作为这次新增菜单的实测结果。

## 住所头衔人物互动

对目标角色右键，使用“授予住所头衔”或“抄没住所头衔”。头衔页保留原有钉选、打开住所和住所管理入口。无独立无地头衔管理窗口。

新人物互动“授予住所头衔”“抄没住所头衔”使用本体专用授予与剥夺流程，包括好感、费用、暴政、法律、契约、理由、接受和拒绝处理。被囚禁者沿用本体无条件接受分支；其他封臣可以拒绝并反抗。打开或取消确认窗口本身不转交资产；本Mod的抄没互动不再要求等待授予后一年。原生家族身份头衔保持保护，能验证为本Mod额外创建的家族型住所头衔允许转交。

游牧身份头衔暂不开放转交，包括Mod额外创建的游牧身份头衔。本体获得头衔时会合并重复的游牧住所，并可能销毁接收方原有载体；当前限制用于保全原生住所。其他住所的查看、创建与原有资源功能保持可用。

## 建筑交换与资源

同类型的两处住所可以交换附属建筑，支持家族庄园、东亚庄园、日式庄园、营地、毡帐、教会住所和商会。管理界面可交换本人住所；与封臣或其下属交换时，右键人物选择“交换庄园”，再确认。确认后，两边的主建筑先对齐到原先较高的等级，永久保留。外部与内部建筑随后按各自原等级对调。头衔、持有人和地点保持原样。点取消时双方建筑保持原状。封臣和本人交换调用同一套主楼升级与附属建筑程序。封臣交换还复用《解锁建设封臣庄园》的独立清单，在部分写入失败时尝试复原双方原有附属建筑。其他 Mod 新增的建筑需要另行接入。

营地给养与毡帐牧群可通过“合并辅助住所资源”汇集到默认住所；创建成功也会尝试汇集。容量不足时留在原处，每次合并显示一条实际汇总。

“销毁”先确认具体头衔，再返还可补偿的建筑资源并销毁本Mod额外住所。消息栏显示实际获得的金币、威望、虔诚、影响力与资源转移数额。给养/牧群优先转到本人其他同类型住所，无法转移的部分随额外住所消失。原生家族、冒险者及其他原生住所载体和来源不明对象始终不能拆除。

## 存档与兼容

升级前保存独立存档副本。正常旧版存档在打开或刷新列表后更新；创建或合并未完成时，应保留异常现场；交换发生异常会显示结果，后续本人交换仍可重新尝试。普通模式隐藏研发决议与诊断按钮。

整文件覆盖gui/window_title.gui、gui/window_domicile.gui、common/on_action/domicile_on_actions.txt，以及七类住所的common/domiciles/buildings建筑定义文件。本Mod只在脚本重建建筑期间暂时绕过建造条件，正常手动建造仍按本体要求。修改相同文件的其他Mod需专门合并；其他Mod新增建筑键不会自动纳入交换。升级游戏后需重新核对这些覆盖文件。脚本使用zz_md/zz_swap前缀；没有新增军区、地图或兵团国库功能。
